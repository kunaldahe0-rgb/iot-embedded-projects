# Embedded Systems & IoT Projects

This repository contains academic and mini projects developed during my Electronics Engineering coursework. 
The projects focus on embedded systems, microcontrollers, sensors, and IoT applications.

## Projects Included

### 1. Non-Invasive Cardiac Blood Flow Monitoring System (Major Project)
- Developed an IoT-based cardiac monitoring system using ESP32 with PPG and ECG sensors.
- Measured heart rate, SpO₂, and ECG signals for real-time monitoring.
- Designed for early abnormality detection and remote observation.

### 2. Parking Assistance System using Arduino
- Built an ultrasonic sensor-based distance measurement system.
- Provided visual and buzzer alerts for safe vehicle parking.
- Implemented real-time obstacle distance calculation.

### 3. Touch-Activated Alarm System using ESP32
- Designed a capacitive touch-based alarm system.
- Integrated buzzer and LED indicators for instant alerts.
- Enabled basic IoT monitoring features.

### 4. Motion-Activated LED Indicator System (STM32)
- Developed an STM32-based motion detection system.
- Used tilt/motion sensors to trigger LED indicators.
- Demonstrated real-time embedded control logic.

## Technologies Used
- Embedded C, C/C++
- STM32, ESP32, Arduino
- Sensors: Ultrasonic, PPG, ECG, Tilt
- IoT Basics
- STM32CubeIDE, EasyEDA
